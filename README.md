## 🚀 Proyectos destacados

> Algunos proyectos son desarrollos freelance o privados, por lo que no todo el código fuente puede estar disponible públicamente.

### 🎓 EDCSST — Sistema Web Institucional

**Plataforma web para una institución dedicada a la formación y certificación en Seguridad y Salud en el Trabajo.**

El proyecto integra un sitio institucional público con herramientas internas para la administración de cursos, personas capacitadas y certificados.

**Características principales:**

* 🌐 Sitio web institucional
* 📚 Catálogo de cursos
* 👨‍🎓 Gestión de personas capacitadas
* 📄 Gestión y consulta de certificados
* 🔎 Verificación pública de certificados
* 🔐 Autenticación administrativa
* 📊 Panel de administración
* 🗂️ Gestión de información institucional

**Stack:**

`Laravel` `PHP` `MySQL` `Blade` `Eloquent` `HTML` `CSS` `JavaScript`

---

### 🎮 Torneo Express — Free Fire

**Mini plataforma web para la gestión de un torneo de Free Fire.**

Proyecto desarrollado para reemplazar un proceso de inscripción basado exclusivamente en mensajería por un sistema web centralizado.

**Características:**

* 📝 Registro de participantes
* 💳 Carga de comprobantes de pago
* ✅ Validación de inscripciones
* 🎮 Registro de IDs de jugadores
* 🔐 Gestión administrativa
* 📢 Publicación de información del torneo
* 🔑 Consulta de datos de acceso a las salas

**Stack:**

`PHP` `MySQL` `JavaScript` `HTML` `CSS`

---

### 👗 Sistema de catálogo y ventas

**Plataforma web para un negocio de venta de ropa con catálogo de más de 150 referencias.**

El objetivo es centralizar la presentación de productos y la gestión interna de clientes y pedidos desde una única aplicación.

**Características previstas:**

* 🛍️ Catálogo de productos
* 🔎 Búsqueda y organización de referencias
* 🛒 Carrito de compras
* 👥 Gestión de clientes
* 📦 Gestión de pedidos
* 🔄 Estados de pedidos
* ⚙️ Panel administrativo

**Stack:**

`Laravel` `PHP` `MySQL` `JavaScript` `HTML` `CSS`

## 🧠 Enfoque de desarrollo

No me interesa únicamente que una aplicación **funcione**. También busco que sea:

```text
┌─────────────────────────────────────────┐
│              SOLUCIÓN WEB               │
├─────────────────────────────────────────┤
│                                         │
│  🎨 Interfaz       → Clara y responsiva │
│  ⚙️ Backend        → Estructurado      │
│  🗄️ Base de datos  → Organizada        │
│  🔐 Seguridad      → Buenas prácticas  │
│  🧩 Arquitectura   → Mantenible        │
│  🚀 Deployment     → Lista para usar   │
│                                         │
└─────────────────────────────────────────┘
```

### Principios que procuro aplicar

* ✅ Código limpio y organizado
* ✅ Separación de responsabilidades
* ✅ Reutilización de componentes
* ✅ Validación de datos
* ✅ Manejo adecuado de errores
* ✅ Control de versiones con Git
* ✅ Diseño responsive
* ✅ Seguridad desde el desarrollo
* ✅ Documentación cuando el proyecto lo requiere
