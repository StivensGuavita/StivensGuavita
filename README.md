## 🏆 Proyectos Destacados

### 📚 Proyectos del Instituto

#### **Sistema de Gestión Académica**
Plataforma web para la gestión integral de calificaciones, asistencia y reportes académicos. Diseñado para facilitar la administración educativa y mejorar la comunicación entre docentes y estudiantes.

**Tecnologías:** JavaScript | React | Node.js | MongoDB

#### **Portal de Estudiantes**
Aplicación web que permite a los estudiantes acceder a sus calificaciones, horarios, tareas y comunicarse directamente con los docentes. Implementa autenticación segura y notificaciones en tiempo real.

**Tecnologías:** HTML5 | CSS3 | JavaScript | PHP | MySQL

---

### 🏨 Proyectos del Hotel

#### **Sistema de Reservas Hotelero**
Plataforma completa de reservas que permite a los clientes consultar disponibilidad, hacer reservas, gestionar pagos y recibir confirmaciones. Incluye panel administrativo para la gestión de habitaciones e ingresos.

**Tecnologías:** React | Node.js | PostgreSQL | Stripe API

#### **Gestión de Inventario y Housekeeping**
Sistema interno para la gestión del inventario de la casa, seguimiento del estado de habitaciones y asignación de tareas a personal de limpieza. Proporciona reportes en tiempo real del estado operativo del hotel.

**Tecnologías:** JavaScript | Express | MySQL | Dashboard Analytics

#### **App Móvil de Servicios Hoteleros**
Aplicación móvil que permite a los huéspedes solicitar servicios adicionales, reportar problemas en la habitación, acceder al menú del restaurante y realizar pedidos desde su dispositivo.

**Tecnologías:** React Native | Node.js | MongoDB | Socket.io
